## Featured Projects

### 01. Offline Sync Conflict Resolution
A backend system designed to handle concurrent edits across devices. Implements version tracking, transactional database operations, idempotency, and field-level conflict detection to resolve synchronization conflicts.

**Technologies:** Node.js · Express.js · PostgreSQL · Docker

[Repository](https://github.com/kalainesan-n/offline-sync-conflict) · [API Documentation](https://offline-sync-conflict-1.onrender.com/api-docs)

### 02. BullWarden — TriAgent Advisory System
A multi-agent AI paper-trading system built around three specialised agents: Analyst, Risk, and Trader. Uses runtime policy enforcement and risk classification to evaluate trading decisions before execution.

**Technologies:** Python · LLM Agents · OpenClaw · ArmorClaw · Alpaca Paper Trading

[Repository](https://github.com/kalainesan-n/sentinel-claw-v1)

### 03. QR-Based Geo-Tagged Attendance
A full-stack attendance application that combines QR scanning and GPS-based geofencing. Validates attendee location against an event's registered coordinates and supports real-time attendance updates.

**Technologies:** React · Node.js · Express.js · MongoDB · Socket.io

[Repository](https://github.com/kalainesan-n/QR-Attendance-System) · [Live Application](https://qr-attendance-system-zeta-two.vercel.app/login)

### 04. Air Quality Forecasting
A time-series machine learning project that predicts carbon monoxide concentration one hour ahead using historical pollutant measurements, temporal features, and lag-based feature engineering. Evaluated against a naive persistence baseline using chronological validation.

**Technologies:** Python · Pandas · NumPy · Scikit-learn · Jupyter Notebook

[Repository](https://github.com/kalainesan-n/AIML-Recruitment-2026-Kalainesan)

## Run Locally

Want to explore the project locally?

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kalainesan-n/KalaiPortfolio11.git
```

**2. Navigate into the project**

```bash
cd KalaiPortfolio11
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

### Production Build

To generate an optimised production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deployment

The portfolio is deployed using **Vercel** and connected to this GitHub repository.

Updates pushed to the connected deployment branch can trigger automatic production deployments.
